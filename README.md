## Что такое Turbo Commander

Turbo Commander загружает рекламный аккаунт в локальную SQLite-базу и даёт
работать с кампаниями, группами, объявлениями, фразами и аудиториями в едином
табличном интерфейсе. Большинство изменений сначала попадает в локальную
очередь: пользователь видит, что именно будет отправлено, может применить
Undo/Redo и только затем нажать «Отправить».

Приложение построено на React 19, TypeScript, Rust и Tauri 2. Основная рабочая
платформа разработки — Linux. Доступны AppImage для Linux и EXE для Windows.

## Основные возможности

- Таблицы кампаний, групп, объявлений, фраз и аудиторий с поиском, фильтрами, массовой правкой и настройкой порядка столбцов.
- Инспектор кампании с разделами «Общее», «Показы», «Цели и аналитика» и «Ограничения».
- Локальная очередь с предпросмотром «Что уйдёт», выборочной отменой и Undo/Redo. Быстрые ссылки, уточнения, корректировки ставок и поддерживаемые операции с аудиториями проходят через эту очередь.
- Редактирование минус-фраз и списков площадок. Из отчёта по поисковым запросам можно добавить в очередь весь запрос или выбранные слова на уровне кампании или группы.
- Месячная статистика, аналитические срезы, быстрые отчёты по запросам, площадкам и фразам.
- История принятых Директом изменений по каждому аккаунту с группировкой по дням, фильтрами и экспортом в TXT.
- Прямые и агентские подключения, восстановление последнего загруженного списка кампаний и управление размером кэша по аккаунтам.
- Кросс-минусовка, склейка дублей и проверка наличия показов фраз. Счётчики длины заголовков и текстов с подсветкой превышений в таблице.

## Как устроена работа с изменениями

```text
Direct API → серверный слепок → локальная рабочая копия → дифф → Отправить → Direct API
```

Правки полей, создание, копирование и поддерживаемые операции со статусами
сохраняются в локальной очереди до нажатия «Отправить».

Отдельные операции с ресурсами аккаунта выполняются сразу. К ним относятся
загрузка медиафайлов в библиотеку, создание общих наборов минус-фраз и работа
с фидами. Назначение медиа объявлению и привязка готового набора минус-фраз
попадают в очередь.
